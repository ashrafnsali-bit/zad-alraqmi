**الموقع منشور على GitHub Pages:** <https://ashrafnsali-bit.github.io/zad-alraqmi/>
**المستودع:** <https://github.com/ashrafnsali-bit/zad-alraqmi>

## التشغيل محليًا

```bash
cd site
node server.js
```

ثم افتح: <http://localhost:4173>

> لا تحتاج أي تثبيت أو مكتبات. الموقع HTML/CSS/JS فقط.

## الأقسام

1. **الواجهة** — الاسم، التعريف، أزرار البدء والأعمال، أرقام سريعة.
2. **من نحن** — التعريف، السوق، نطاق العمل، المزايا الثلاث.
3. **الرؤية والرسالة والقيم** — الأربع قيم.
4. **لماذا نحن** — الأسباب الأربعة.
5. **الخدمات** — السبع خدمات + الإنتاج البصري + ما بعد الإنتاج + الفعاليات + إدارة المحتوى.
6. **مراحل العمل** — الخمس مراحل.
7. **من منصاتنا** — معرض ٩ أعمال مع عارض صور (Lightbox).
8. **نماذج من إنتاجنا** — ٣ فيديوهات مع Posters ومشغل فيديو.
9. **أعمال نتشرف بعرضها** — ٨ جهات.
10. **عملاؤنا وشركاؤنا** — ٢٤ شعارًا.
11. **تواصل** — الجوال، البريد، الموقع، السجل التجاري، واتساب، وتحميل البروفايل.

## إضافة / تبديل الفيديوهات

القسم الحالي يعرض ٣ فيديوهات:

| الملف | المدة | المقاس |
|---|---|---|
| `assets/video/reel-01.mp4` | 01:02 | 1280×720 |
| `assets/video/reel-02.mp4` | 01:01 | 1280×720 |
| `assets/video/reel-03.mp4` | 00:52 | 1280×720 |

لاستبدال أي فيديو: ضع الملف بنفس الاسم في `assets/video/`، وبدّل صورة الغلاف بنفس الاسم في `assets/img/` (`reel-01.jpg` …) بمقاس ١٢٨٠×٧٢٠. لا حاجة لتعديل الكود.

**مواصفات التصدير الموصى بها:** MP4 · H.264 · 1280×720 · 25fps · AAC 96k · `faststart`، وحجم أقل من ١٢ ميجابايت للدقيقة. أمر ffmpeg المستخدم:

```bash
ffmpeg -i input.mp4 -map_metadata -1 \
  -vf "scale=1280:-2,fps=25" \
  -c:v libx264 -preset slow -crf 26 -pix_fmt yuv420p -profile:v high -level 4.0 \
  -c:a aac -b:a 96k -ar 48000 -movflags +faststart assets/video/reel-01.mp4
```

**إضافة فيديو رابع:** انسخ بطاقة `.reel-card` في `index.html` وبدّل الرقم واسم الملف والعنوان والمدة.

> الفيديوهات تُحمَّل عند الضغط فقط (`preload="none"` عمليًا)، لذلك لا تؤثر على سرعة فتح الصفحة.

## النشر

الموقع منشور عبر **GitHub Pages** من الفرع `main` (جذر المستودع):

- **الموقع:** <https://ashrafnsali-bit.github.io/zad-alraqmi/>
- **المستودع:** <https://github.com/ashrafnsali-bit/zad-alraqmi>

أي `git push` إلى `main` يحدّث الموقع تلقائيًا خلال دقيقة:

```bash
git add -A
git commit -m "وصف التعديل"
git push
```

للنشر على منصات أخرى (Netlify / Vercel / cPanel) ارفع محتويات المجلد كما هي:

- **Netlify / Vercel:** اسحب المجلد في لوحة الموقع.
- **GitHub Pages:** مفعّل حاليًا (فرع `main`، مجلد الجذر).
- **استضافة عادية (cPanel):** ارفع داخل `public_html`.

عند ربط دومين خاص في GitHub Pages: Settings → Pages → Custom domain، ثم أضف ملف `CNAME` يحتوي اسم الدومين في جذر المستودع.

## ملاحظات

- التصميم متجاوب بالكامل (جوال / تابلت / سطح مكتب) ويدعم RTL.
- الحركات تحترم إعداد `prefers-reduced-motion`.
- الصور محسّنة للويب (إجمالي الصور ≈ ٢ ميجابايت + الفيديوهات ≈ ٣٠ ميجابايت تُحمَّل عند الطلب + البروفايل ٢٤ ميجابايت للتحميل).
- لم يكن في ملف PowerPoint شعار رسمي مستقل، لذلك استُخدم توقيع نصي «ز» داخل إطار ذهبي. لو عندكم ملف الشعار (SVG/PNG) أرسله وسيُركّب مكانه مباشرة.
